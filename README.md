My long-term direction is data analysis and data science. I am currently strengthening the fundamentals first: clean Python, structured SQL, exploratory data analysis, Jupyter workflows, database design, and the early mathematics and tooling needed for machine learning.

- Building stronger **Python + SQL** workflows for data cleaning, querying, and analysis.

## Featured Projects

### Python Data Analysis Sandbox

A learning log for my transition into data analysis. This repository contains daily Python practice, raw Jupyter notebooks, syntax exercises, and early experiments with data manipulation. It is intentionally labeled as a sandbox rather than a polished portfolio project, but it shows consistency, learning momentum, and the exact direction I am building toward.

**What it demonstrates:** Python fundamentals, Jupyter usage, analytical thinking, consistent practice, and early data-cleaning/data-analysis workflows.

**Tech used:** Python, Jupyter Notebook, Google Colab, basic data analysis concepts.

[View Repository](https://github.com/ameer-muawiyah/Python-Data-Analysis-Sandbox)

### OOP Studio LMS

A full-stack learning management system built as a second-semester Computer Science project. It includes adaptive OOP quizzes, real-time exam timers, student dashboards, professor views, exam history tracking, and a browser-based Java code runner. Although it is not a data analysis project, it is important portfolio evidence because it shows database design, backend logic, data persistence, user records, and structured application architecture.

**What it demonstrates:** MySQL-backed web development, Spring Boot architecture, REST-style data flow, student performance tracking, and the ability to build systems that collect and display meaningful user data.

**Tech used:** Java, Spring Boot, Spring MVC, Spring Data JPA, Thymeleaf, MySQL, Hibernate, HTML, CSS, JavaScript, Maven.

[View Repository](https://github.com/ameer-muawiyah/OOP-Studio-LMS)

### Student Management App JavaFX

A desktop student management system built with JavaFX and MySQL. The application supports persistent storage, CRUD operations, input validation, dynamic table updates, and a clean MVC/DAO structure. This project is especially useful for my data path because it connects user-facing software with structured database operations.

**What it demonstrates:** Database integration, SQL-backed CRUD logic, JDBC, separation of concerns, validation, and practical handling of structured records.

**Tech used:** Java, JavaFX, FXML, MySQL, JDBC, Maven, CSS, Scene Builder.

[View Repository](https://github.com/ameer-muawiyah/Student-Management-App-JavaFX)
